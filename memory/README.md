# memory/

One fact per file. Each file is a single preference, correction, decision, or recurring note about **this director and their films** — never the studio's craft.

**Format:**
```markdown
---
name: <short-kebab-slug>
type: preference | correction | decision | note
---

<the fact, in one or two sentences>
```

After creating a file here, add a one-line pointer to `../MEMORY.md`:
`- [Title](memory/<slug>.md) — one-line hook`

Update the existing file rather than duplicating. Delete notes that turn out to be wrong.
